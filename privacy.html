Privacy Policy

Effective date: September 1, 2026

Scope

AutoShorts is a private automation tool used by its operator for the operator's own authorized Google Drive and YouTube accounts.

Google and YouTube data accessed

  • Google Drive file metadata and authorized video file contents using read-only Google Drive access.
  • YouTube upload data, uploaded video IDs, limited authorized channel information, and playlist information.
  • OAuth access and refresh credentials required for the explicitly authorized automation.

Use of data

Google user data is used only to operate the authorized AutoShorts workflow. This includes selecting authorized Google Drive videos, temporarily transferring videos for processing and upload, uploading videos to the authorized YouTube channel, generating upload metadata from source filenames, preventing duplicate uploads, and adding successfully uploaded videos to the operator's designated YouTube playlist.

Sharing

AutoShorts does not sell Google user data. AutoShorts does not share Google user data with advertisers, data brokers, or unrelated third parties.

Storage and security

OAuth credentials and automation-state data are stored on a private server controlled by the operator with restricted file permissions. Temporary downloaded video copies are removed after processing. Source files stored in Google Drive are not deleted, renamed, or moved by AutoShorts.

Retention, revocation, and deletion

Upload-state identifiers are retained only as needed to prevent duplicate publishing.

OAuth credentials are retained until Google access is revoked or the AutoShorts automation is discontinued.

The operator can revoke AutoShorts access to Google services at any time through Google Account permissions.

After authorization is revoked or AutoShorts is discontinued, stored OAuth credentials and related automation-state data can be permanently deleted from the private server.

Temporary downloaded video files are deleted after processing and are not retained as permanent copies by AutoShorts.

Google API Services User Data Policy
