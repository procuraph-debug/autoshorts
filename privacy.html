Privacy Policy

Effective date: September 1, 2026

Scope

AutoShorts is a private automation tool used by its operator for the operator's own authorized Google Drive and YouTube accounts.

Google data accessed

  • Google Drive file metadata and authorized video file contents using read-only Drive access.
  • YouTube upload data, video IDs, limited authorized channel information, and playlist information.
  • OAuth access and refresh credentials required for the authorized automation.

Use of data

Google user data is used only to select authorized Drive videos, temporarily transfer them for upload, upload them to the authorized YouTube channel, create metadata from filenames, avoid duplicate uploads, and add uploaded videos to the designated playlist.

Sharing

AutoShorts does not sell Google user data and does not share it with advertisers, data brokers, or unrelated third parties.

Storage and security

OAuth credentials and automation state are stored on a private server with restricted file permissions. Temporary downloaded videos are removed after processing. Source Drive files are not deleted, moved, or renamed.

Retention and deletion

Upload-state identifiers are retained to prevent duplicate publishing. OAuth credentials are retained until access is revoked or the automation is discontinued. The operator can revoke Google access at any time through Google Account permissions.

Google Privacy Policy

Google's Privacy Policy is available at https://policies.google.com/privacy .

Google API Services User Data Policy

AutoShorts's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
