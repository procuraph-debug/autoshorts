AutoShorts

Private Google Drive to YouTube automation for an authorized YouTube channel.

What AutoShorts does

AutoShorts reads authorized video files from a designated Google Drive folder, selects the next unposted video, temporarily downloads it to a private server, derives the YouTube title, description, hashtags, and tags from the source filename, uploads the video to the operator's authorized YouTube channel, and adds successful uploads to the designated playlist.

Google API usage

  • Google Drive access is read-only.
  • YouTube access is used for uploading, limited channel verification, and playlist management.
  • The tool is private and is not offered as a public multi-user service.
  • Google user data is not sold or provided to advertisers.

Data handling

Source Drive files are not deleted, moved, or renamed. Temporary server copies are removed after processing. OAuth credentials are stored on the operator's private server with restricted permissions.
